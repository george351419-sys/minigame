二进制密码小游戏

输入 6 个 0 或 1，像小侦探一样解开密码——发现二进制如何变成十进制数字！

输入密码（6 位二进制）

前 3 位 → 十位
后 3 位 → 个位

只能使用 0 和 1，共 6 位

计算过程

十位 100 → 二进制转十进制 = 4

1×4 + 0×2 + 0×1 = 4

个位 101 → 二进制转十进制 = 5

1×4 + 0×2 + 1×1 = 5

最终答案

45

合起来：4 作为十位，5 作为个位 → 45

小知识

计算机里只用 0 和 1 两种符号，这叫二进制。每多一位，权值就翻倍（从右往左：1、2、4）。

这个游戏把 6 位密码拆成两半：前 3 位决定十位数，后 3 位决定个位数，就像两把小小的二进制锁！

示例：100101 → 十位 100=4，个位 101=5 → 45
拖动开关或输入 6 位数字，即时看到结果
